About QuickNotes

QuickNotes is a lightweight, fast web application designed to help you capture your thoughts instantly. It provides a distraction-free environment tailored for speed and simplicity.

How to use QuickNotes

  1. Click the "New Note" button on the home screen.
  2. Type your ideas into the text area provided.
  3. Press save to store your note locally.

Features

  • Instant load times
  • Clean, minimalist interface
  • Secure local storage

Keyboard shortcuts

Shortcut Action
Ctrl + N Create New Note
Ctrl + S Save Current Note
